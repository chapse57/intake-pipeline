A contact form setup that tells you when it breaks.

I set up form intake for web agencies and small B2B firms. It runs on this page first, so you can try it yourself.

  • Saved first — every inquiry is stored in Notion before anything else runs
  • Spam screened — unclear ones go to review, not the bin
  • Alerts — a Slack message for each new inquiry
  • Held during outages — delivered when the backend is back
  • Watched from outside — a health check every 5 minutes, down and back-up alerts, a daily spam digest

Build notes and the operations log are on GitHub.
